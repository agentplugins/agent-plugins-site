title: JSON Schemas
description: Canonical machine-readable schemas for Agent Plugins manifests, MCP configuration, and hooks configuration.
type: reference
---

Agent Plugins publishes separate JSON Schemas for the plugin manifest, MCP server configuration, and hooks configuration. Clients use each canonical `$schema` identifier to select locally supported validation and interpretation rules; they do not retrieve schemas while loading a plugin.
